**How to Install Lights Out Application**<br>

**Please Clone the repository using commands**<br>

To clone your GitHub repository, use:<br>

git clone https://github.com/AsadIftikhar22/TMS-_AsadIftikhar.git<br>

Then enter the folder:<br>

cd TMS-_AsadIftikhar<br>

Clone master specifically<br>

git clone -b master https://github.com/AsadIftikhar22/TMS-_AsadIftikhar.git<br>

Then:<br><br>
**Using Installer exe file on Windows** <br>

1. Navigate to the **BlueRock TMS LightOut Installer**
2. Open the **LightsOut.Wpf.exe**
3. It will execute the Desktop Application
4. Execute the test cases provided by clicking on Solve
5. For New test case simply add a new .txt file inside the **Samples Folder**<br><br>

**Running through Code** <br>

Navigate to the **TMS_LightsOut_Project_.Net**<br>

1. Open in Visual Studio 2022 with .Net 8 version Installed<br>
2. Make Sure through Visual Studio Installer that the WPF Packages are installed<br>
3. Restart Visual Studio 2022 after Installing WPF Packages<br>
4. Open Project > Navigate to **TMS_LightsOut_Project_.Net** go to **.slnFile** select it.<br>
5. Run Project Using Visual Studio
6. For New test case simply add a new .txt file inside the **Samples Folder**
